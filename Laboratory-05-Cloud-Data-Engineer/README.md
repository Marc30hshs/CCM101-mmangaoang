
# Laboratory 05 – Cloud Data Engineer

## Mission Overview
This laboratory focuses on researching cloud storage types and deploying MinIO, an S3-compatible object storage server, using Docker.

## Objectives
- Understand block, file, and object storage.
- Deploy MinIO using Docker.
- Access the MinIO Web Console through port 9001.
- Create a bucket named `client-photos`.
- Upload a sample file and document the deployment.

## Tools Used
- GitHub
- KillerCoda Ubuntu Playground
- Ubuntu Linux
- Docker
- MinIO Object Storage
- Markdown

## Skills Learned
- Linux command-line operations
- Docker container deployment
- Environment variable configuration
- Cloud storage concepts
- Bucket creation and file uploading
- Technical documentation
- GitHub version control
