# Checkpoint 7 – Mission Reflection

## 1. Which cloud infrastructure component do you think is the most important? Why?

For me, **networking** is the most important cloud infrastructure component because it connects users, servers, applications, and storage resources. Even if a cloud server has powerful computing resources and enough storage, those resources would be difficult to use without a reliable network connection.

## 2. How does Linux support cloud computing?

Linux provides a stable and flexible environment for running cloud workloads. Through the terminal, administrators can monitor resources, manage files, configure networks, install applications, and control services without depending on a graphical interface. Its efficiency and strong server support make it a practical operating system for cloud environments.

## 3. Why is technical documentation important before deploying infrastructure?

Technical documentation helps organize information about the infrastructure before changes are made. It provides a reference for resources, configurations, commands, and planned designs, which can reduce mistakes and make troubleshooting easier. Good documentation also allows other team members to understand and maintain the environment.

## 4. What new skills did you learn during this laboratory activity?

I learned how to investigate a Linux server using commands such as `lscpu`, `free`, `df`, `findmnt`, `hostname`, and `ip`. I also learned how to identify cloud infrastructure components, compare AWS, Azure, and GCP services, create a basic cloud architecture diagram, and organize technical information using Markdown.

## 5. How has your GitHub portfolio improved after completing this mission?

My GitHub portfolio became more organized and more focused on practical cloud and Linux skills. Instead of only showing code, it now demonstrates system investigation, infrastructure documentation, cloud service comparison, and architecture design. The completed files also provide evidence of my ability to document technical work clearly.

## Final Reflection

This mission helped me understand that cloud computing involves more than simply using online services. It depends on infrastructure working together, and Linux provides useful tools for examining and managing that infrastructure. Overall, the activity gave me practical experience that I can continue building on in future cloud and system administration projects.
