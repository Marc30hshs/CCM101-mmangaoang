# Automation Research

## 1. Bash Script

A Bash script is a file containing Linux commands that run automatically in sequence. The `#!/bin/bash` line, called a shebang, tells Linux to use Bash to execute the script.

## 2. Variables

Variables store information such as folder paths and filenames. They make scripts easier to update because we can change a value in one place instead of editing the same path multiple times.

## 3. Cron Job

A cron job is a Linux feature that runs commands or scripts automatically at a scheduled time. It is important in cloud operations because it can automate regular tasks such as backups and system maintenance.
