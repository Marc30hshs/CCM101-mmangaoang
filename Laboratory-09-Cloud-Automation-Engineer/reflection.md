
# Mission Reflection

Cloud automation is important when managing hundreds of cloud servers because it saves time and reduces repetitive manual work. Instead of performing the same task on every server, administrators can use scripts to execute commands automatically. Automation also helps maintain consistency and makes regular tasks, such as backups, easier to manage.

However, automation also has potential dangers. A small mistake in a script can cause serious problems, especially when it runs on many servers. For example, a destructive command with an incorrect path could delete important files across 1,000 servers. This is why scripts should be reviewed, tested, and checked carefully before being deployed in a production environment.

Writing a Bash script was different from creating a Docker Compose YAML file in Laboratory 6. Bash scripts contain commands that execute step by step to perform tasks such as creating folders and compressing files. Docker Compose uses YAML to describe services, configurations, networks, and volumes so that multiple containers can work together.

From Laboratory 1 to Laboratory 9, my understanding of cloud computing has improved. I learned that cloud computing involves more than simply using online storage or virtual machines. It also includes infrastructure management, container deployment, storage solutions, security, and automation. Each laboratory helped me understand how different cloud technologies work together.

The role I enjoyed most was the Cloud Automation Engineer because it showed me how to make repetitive tasks easier through scripting. I learned how to create a backup script, change file permissions, and schedule automatic execution using Cron. These skills are useful because they can help prevent data loss and improve the efficiency of system administration.

Overall, this laboratory taught me the importance of automation, careful testing, and proper documentation. I also learned that automated tasks must be monitored to ensure they work correctly and protect important data.
