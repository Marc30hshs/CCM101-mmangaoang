
# ☁️ AWS Research

## 📌 Overview

**Amazon Web Services (AWS)** is a cloud platform developed by Amazon that provides various services for computing, storage, databases, networking, security, and more. It allows users to build and run applications online without needing to maintain their own physical servers.

AWS is used by developers, businesses, startups, and large organizations for different types of projects and applications.

## 🌎 Global Infrastructure

AWS uses **Regions** and **Availability Zones** to organize its cloud infrastructure.

* **Regions** – Geographic locations where AWS provides its cloud services.
* **Availability Zones** – Separate locations within a Region that help improve system reliability and availability.
* **Local Zones** – Provide AWS resources closer to users in specific locations.
* **Wavelength Zones** – Designed for applications that require very low network latency.

Using multiple Availability Zones can help applications remain operational even if one location experiences an issue.

## 🖥️ AWS Management Console

The **AWS Management Console** is a web-based dashboard used to access and manage AWS services. Users can create and configure resources, monitor applications, manage security, and check billing information.

## ⚙️ Four Core AWS Services

### 1. Amazon EC2

**Amazon Elastic Compute Cloud (EC2)** provides virtual servers that users can configure and use to run websites, applications, databases, and other workloads.

### 2. Amazon S3

**Amazon Simple Storage Service (S3)** is a cloud storage service used to save files and data such as documents, images, videos, backups, and datasets.

### 3. AWS IAM

**AWS Identity and Access Management (IAM)** is used to control access to AWS resources. It allows administrators to manage users, roles, permissions, and security policies.

### 4. Amazon RDS

**Amazon Relational Database Service (RDS)** provides managed relational databases. It helps simplify database setup, maintenance, backups, and other administrative tasks.

## ⭐ Advantages of AWS

1. **Many Available Services** – AWS offers numerous services for computing, storage, databases, networking, security, analytics, and artificial intelligence.
2. **Worldwide Infrastructure** – AWS operates in different geographic locations, allowing applications to be deployed closer to their users.
3. **Scalable Resources** – Computing and storage resources can be adjusted based on the requirements of an application or organization.

## 🏢 Common Enterprise Applications

AWS can be used by organizations for:

* 🌐 Website and web application hosting
* 💾 Data backup and recovery
* 🗄️ Database management
* 🛒 E-commerce applications
* 🤖 Artificial Intelligence and Machine Learning
* 📊 Big data processing
* 🧪 Software development and testing
* 🌍 Global application deployment

## 📝 Conclusion

AWS is a flexible cloud computing platform that provides a wide variety of services for individuals, developers, and organizations. Its global infrastructure, scalable resources, and extensive service options make it a useful platform for building and managing modern cloud-based applications.
