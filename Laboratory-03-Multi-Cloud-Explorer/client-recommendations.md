
# 👥 Client Recommendations

## 🏢 Client A – Startup Business

### Suggested Cloud Platform: AWS

For a startup that is still developing its mobile application, **AWS** would be a suitable option. The company can start with basic cloud resources and increase them as the application gains more users. AWS also has managed services that can lessen the technical workload of a small development team.

Instead of building a complicated infrastructure from the beginning, the startup can use a simple setup and add more AWS services when the business and application requirements increase.

### ☁️ Suggested Services

* Amazon EC2
* Amazon S3
* Amazon RDS
* Amazon CloudFront

### Why AWS?

These services cover the main requirements of the application, including server computing, data storage, database management, and faster content delivery.

# 🎓 Client B – University

### Suggested Cloud Platform: Microsoft Azure

For the university, **Microsoft Azure** is a practical choice because its existing environment already relies on Microsoft technologies such as Windows Server, Microsoft 365, and Active Directory.

Azure allows the university to connect its current systems with cloud-based services without completely changing its existing technology environment. It can also support identity management and hybrid connections between campus infrastructure and cloud resources.

### ☁️ Suggested Services

* Azure Virtual Machines
* Microsoft Entra ID
* Azure SQL Database
* Azure Blob Storage

### Why Azure?

Azure provides a convenient way for the university to modernize its infrastructure while keeping compatibility with its existing Microsoft-based systems. The migration can also be performed gradually instead of transferring all services at once.

# 🤖 Client C – AI Research Organization

### Suggested Cloud Platform: Google Cloud

For an organization primarily focused on **Artificial Intelligence and Machine Learning**, I would recommend **Google Cloud**. The client needs strong computing capabilities, data storage, and tools for developing AI and ML applications.

Google Cloud is well suited for workloads involving large datasets, machine learning models, and high-performance computing. In this case, specialized AI and data capabilities are more important than simply having a large number of general cloud services.

### ☁️ Suggested Services

* Compute Engine
* Google Kubernetes Engine (GKE)
* Cloud Storage
* Vertex AI

### Why Google Cloud?

The recommended services provide the client with computing power, storage for research datasets, Kubernetes support, and tools for creating and managing AI and machine learning solutions.

---

# 🛒 Client D – International E-Commerce Business

### Suggested Cloud Platform: AWS

For a large e-commerce company serving customers from different countries, **AWS** would be my recommended platform. Online stores can experience unpredictable traffic, especially during promotional events, holidays, and major sales campaigns.

AWS can help distribute incoming traffic, increase computing capacity when needed, store application data, and deliver website content efficiently to customers in different locations. The company can also design its infrastructure across multiple Availability Zones and Regions to improve availability and reliability.

### ☁️ Suggested Services

* Amazon EC2
* Elastic Load Balancing
* Amazon RDS
* Amazon CloudFront
* Amazon S3
* Amazon Route 53

### Why AWS?

These services can be combined to create an infrastructure capable of handling high traffic, distributing workloads, storing information, and serving customers across multiple geographic locations.

| --------------------------- | -------------------- | -------------------------------------------------------- |
| Startup Business            | AWS                  | Can easily scale resources as the company develops       |
| Large Enterprise            | AWS                  | Offers extensive services and enterprise-level solutions |
| Microsoft-Based Environment | Azure                | Works well with existing Microsoft technologies          |
| AI and Machine Learning     | Google Cloud         | Strong tools for AI, ML, and data-intensive workloads    |
| Kubernetes Applications     | Google Cloud         | GKE provides managed Kubernetes capabilities             |
| Worldwide Web Application   | AWS                  | Supports global deployment and scalable infrastructure   |

## 🎯 Final Recommendation

The most appropriate cloud platform depends on the specific needs of each organization. Factors such as existing technologies, budget, security requirements, technical expertise, expected growth, and application design should all be considered before making a decision.

Based on the given scenarios, **AWS** is a strong general-purpose option, **Azure** is more suitable for organizations built around Microsoft technologies, while **Google Cloud** is a good fit for projects that focus heavily on **AI, machine learning, data, and Kubernetes**.
