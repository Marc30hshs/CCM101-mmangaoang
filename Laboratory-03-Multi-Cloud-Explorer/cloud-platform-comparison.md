
# ☁️ Cloud Computing Platforms: AWS, Azure, and Google Cloud

| Feature           | Amazon Web Services                            | Microsoft Azure                    | Google Cloud                          |

| Year Introduced   | 2006                                           | 2010                               | 2008                                  |

| Recommended For   | Different types of businesses and applications | Companies using Microsoft products | Data-driven and cloud-native projects |

## 💡 My Comparison of the Three Platforms

### 1. Provider with the Most Services

Among the three platforms, I consider **AWS** to have the most extensive collection of cloud services. It provides solutions for different areas, including computing, databases, storage, networking, security, and analytics. Because of this, users have many options when creating a cloud-based system.

### 2. Best Choice for Microsoft-Based Environments

For companies that already depend on Microsoft products, **Azure** would be the most suitable choice. It can work together with technologies such as Windows Server, SQL Server, Microsoft 365, and Microsoft identity systems. This makes Azure convenient for businesses moving their existing systems into the cloud.

### 3. Best Platform for AI and Kubernetes

For **Artificial Intelligence, Machine Learning, and Kubernetes**, I would select **Google Cloud**. Google has strong technologies for handling data and AI workloads, while **Google Kubernetes Engine (GKE)** provides tools for running containerized applications using Kubernetes.

### 4. My Preferred Cloud Platform

If I were given the opportunity to select one platform, I would go with **AWS**. One reason is its flexibility and the number of services available. For someone studying Information Technology, it can also provide experience in different cloud areas such as computing, storage, databases, networking, and security.

# 🔄 Checkpoint 5 – Similar Services Across Cloud Providers

Different cloud companies often provide services that perform similar tasks. The names may be different, but their main purpose can be almost the same.

| Cloud Function            | AWS | Microsoft Azure        | Google Cloud   |
| ------------------------- | --- | ---------------------- | -------------- |
| Cloud-Based Server        | EC2 | Azure Virtual Machines | Compute Engine |
| File/Object Storage       | S3  | Blob Storage           | Cloud Storage  |
| User & Permission Control | IAM | Microsoft Entra ID     | Cloud IAM      |
| Managed SQL Database      | RDS | Azure SQL Database     | Cloud SQL      |
| Container Orchestration   | EKS | AKS                    | GKE            |

## 📌 Key Takeaway

AWS, Azure, and Google Cloud all provide the fundamental tools needed to build cloud applications. However, each company has its own approach to features, pricing, integrations, and resource management.

For example, a developer can use **EC2, Azure Virtual Machines, or Compute Engine** when a virtual server is needed. Likewise, **EKS, AKS, and GKE** can be used to manage Kubernetes-based applications.

The choice of cloud provider should therefore depend on the project's goals, required services, budget, existing technologies, and technical requirements rather than simply choosing the platform with the most features.
